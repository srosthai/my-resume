# Home surface — direction contract

Mode: Experience (portfolio showcase; the work and the person lead).

THESIS: The home page is a night-operator status deck for one developer: identity, telemetry, and proof arranged as a single cinematic console. It refuses the card-grid portfolio default and the light drafting-sheet look of the rest of the site.

OWN-WORLD: A full-bleed amber field — burnt orange gradients from #F97316 through #B03A05 to #1A0700 — with warm white ink (#FFF6EC), hairline rules in rgba(255,180,110,.28), dark glass scrims, and mono telemetry type. Display set in Michroma, body in Chakra Petch, data in JetBrains Mono. Component language: HUD spec tables, corner ticks, circular icon controls, one amber pill CTA.

STORY: A visitor learns who SROS THAI is, sees the live facts (role, stack, local time, availability, counts), and leaves through projects, feeds, notes, or contact.

FIRST VIEWPORT: Left column carries the stencilled name block, role line, description, and icon controls. Center holds the cut-out portrait of SROS THAI (public/me-2-cutout.png) rim-lit against the brightest part of the field. Bottom-right is a DEVELOPER SPECS table (role, stack, local time, status, shipped counts). Bottom-left is an ID credential card with the primary "See projects" action. A thin status strip runs across the top.

FORM: Pinned by the owner's reference image, position 1 on the list (the reference itself). Seed rolled but overridden by the brief: the user pinned this direction, so the roll cannot displace it.

RAISED BY (verdicts closed before borrowing): grid discipline — Swiss poster wall, declined (module and hairline rules now carry meaning: spec rows and stat cells sit on the 12-track module). Pointer light — plankton wake, competitive (one amber bloom follows the pointer, slow ease, single light source). Live instruments — VU bridge, competitive (clock, counts and status are live readings in tabular numerals). Single bloom — CRT arcade, declined (glow concentrated on the portrait rim and nowhere else). Custody rows — provenance ribbon, declined (label/value hairline rows carry every shipped fact).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
